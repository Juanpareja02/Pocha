# Preparación para i18n

La aplicación tiene español como idioma inicial y registra `AppStrings` como
un `LocalizationsDelegate` propio en `mobile/lib/l10n/app_strings.dart`.

La capa contiene el copy transversal del producto y funciones para textos con
cantidades, rondas, puntuaciones, pujas y temporizadores. Los delegates de
Material también se registran para que controles y mensajes del sistema sigan
siendo accesibles en español.

Las decisiones de juego, nombres de palos, rangos y mensajes de validación que
pertenecen al dominio se mantienen fuera de la capa de localización. La
siguiente iteración puede sustituir el contenido español por recursos ARB y
generación de `AppLocalizations` sin cambiar contratos de motor, sesiones o
controladores.
