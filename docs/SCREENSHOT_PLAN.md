# Plan de capturas para tiendas

## Objetivo

Crear un paquete reproducible de capturas de la release candidate para Google
Play, usando solo datos sintéticos y una build identificable.

## Secuencia mínima

1. Inicio: acceso a calculadora, solitario, amistosa y ranked.
2. Calculadora: ronda con pujas y resultado.
3. Solitario: mesa con cartas, turno y marcador.
4. Amistosa: lobby con código ficticio y participantes sintéticos.
5. Online: mesa con conexión estable y acción válida.
6. Ranked: temporada, rango y leaderboard.

## Criterios de aceptación

- Capturas tomadas en un dispositivo Android físico.
- Misma versión de la RC que se pretende enviar a revisión.
- Sin tokens, correos, nombres reales, datos de soporte ni información de
  desarrollo.
- Texto y contraste legibles en el tamaño final de tienda.
- Cada pantalla representa una función que ha pasado la QA correspondiente.
- El equipo conserva originales y versiones recortadas con nombres que incluyan
  plataforma, dispositivo, idioma y versión.

La generación de las imágenes finales sigue siendo una acción humana porque
requiere dispositivos reales y cuentas/configuración externas.
